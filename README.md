AIM:\
\
&#x9;To sketch the given drawing with dimensions using fusion 360 tool.\
REQUIREMENTS:\
Autodesk fusion 360\
Windows 10\
16GB of RAM (integrated graphics recommend 2 GB or more)\
2.5 Mbps or faster download; 500 Kbps or faster upload\
PROCEDURE:\
Open a new file and then select the sketch icon.\
Select the plane of sketching.\
Use Sketching features (line, circle, arc, rectangle, polygon, etc.,) to draw to given sketch\
\
\
\
\
\
\
Use sketch modifying features (trim, mirror, move, etc.,) to edit the sketch\
\
Use the Constraints feature and apply the Tangent tool to join the circles smoothly and create the required curves.\
\
\
\
&#x9;\
Draw a vertical construction line through the centre of the sketch. \
Draw a horizontal construction line through the centre of the middle portion. \
Draw two concentric circles at the top with (diameters) Ø32 mm and Ø20 mm. \
Position the centre of the top circles 65 mm above the horizontal centre line. \
Draw the two outer side curves using R64 and make them symmetrical about the vertical centre line. \
Draw the middle outer circular portion with Ø66 mm and trim the unwanted portions. \
Draw the central four-lobed opening using R6 arcs and the Ø40 mm dimension. \
Draw the left and right circular end portions using R20 and R7 as shown. \
Draw the inner circles of the left and right portions with R10. \
Position the left and right end centres 47 mm from the vertical centre line on both sides. \
Draw the lower central circular portion with Ø20 mm and its inner hole with Ø10 mm. \
Create the connecting curves using R10 and R20. \
Apply the vertical dimensions 26 mm and 24 mm to position the side and bottom features correctly. \
Use Trim to remove the unwanted portions and form the final profile. \
Apply Tangent, Coincident, Symmetry, Horizontal/Vertical constraints wherever required. \
Check all the given dimensions and ensure that the complete profile matches the reference drawing. \
Finish the sketch after completing all the required dimensions and constraints. \
The finished sketch should look like this. \
Line – Used to draw the straight edges of the diagram.\
Circle – Used to create the circular holes/features in the diagram.\
\
Trim – Used to remove unwanted portions. \
\
\
\
\
Tangent – Used to create smooth contact between the required lines/circles. \
\
Dimension – Used to apply the given measurements. \
\
Mirror – Used to create a symmetrical copy of the selected part on the opposite side of the diagram. \
\
After finishing the sketch, click the Finish Sketch option to complete the sketch. \
&#x9;\
After finishing the sketch, switch to drawing mode to plot the sketch in ISO standard.\
\
\
\
\
\
\
\
\
Then, open the From Design model, save the file, select the Manual option, and click OK to open the drawing in ISO standard mode. \
\
After opening the drawing in ISO Standard mode, change the scale ratio to 1:0.9. Then, use the Dimension tool to add all the required dimensions according to the uploaded sketch.\
